[[9-16-1-p16hf1-2-november-2026]]
== 9.16.1 P16HF1 (2. November 2026)

Der Patch 9.16.1 P16HF1 ist jetzt für Cloud Volumes ONTAP für alle Cloud-Anbieter verfügbar. Dieser Patch ist mit dem ONTAP hotfix für 9.16.1 kompatibel.

Für Ihre Cloud Volumes ONTAP Systeme erhalten Sie möglicherweise in der Console eine Aufforderung zum Upgrade auf diesen Hotfix. Dieser Hotfix wird jedoch nur unterstützt, wenn die Version des Console Agent 4.12.0 oder höher ist. Wenn die Version des Console Agent älter als 4.12.0 ist, kann die Aufforderung ignoriert werden.

link:https://docs.netapp.com/us-en/console-setup-admin/whats-new.html#console-agent-4-12-0["Console Agent 4.12.0"^]

[[upgrade-notes]]
== Upgrade-Hinweise

Lesen Sie diese Hinweise, um mehr über das Upgrade auf diese Version zu erfahren.



[[how-to-upgrade]]
=== So führen Sie ein Upgrade durch

Upgrades von Cloud Volumes ONTAP müssen über die Konsole durchgeführt werden. Sie sollten Cloud Volumes ONTAP nicht mithilfe von System Manager oder der CLI aktualisieren. Dies kann die Systemstabilität beeinträchtigen.

link:http://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/task-updating-ontap-cloud.html["Erfahren Sie, wie Sie ein Upgrade durchführen, wenn die Konsole Sie benachrichtigt."^].



[[supported-upgrade-path]]
=== Unterstützter Upgradepfad

Sie können in AWS, Azure und Google Cloud von der Version 9.15.1 auf Cloud Volumes ONTAP 9.16.1 aktualisieren.  Die Konsole fordert Sie auf, kompatible Cloud Volumes ONTAP -Systeme auf diese Version zu aktualisieren.



[[downtime]]
=== Ausfallzeit

* Das Upgrade eines Einzelknotensystems schaltet das System für bis zu 25 Minuten offline, währenddessen die E/A unterbrochen wird.
* Das Upgrade eines HA-Paares erfolgt ohne Unterbrechung und die E/A erfolgt ohne Unterbrechung.  Während dieses unterbrechungsfreien Upgrade-Prozesses wird jeder Knoten gleichzeitig aktualisiert, um den Clients weiterhin E/A-Funktionen bereitzustellen.
